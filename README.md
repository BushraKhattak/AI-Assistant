# 🤖 AI Personal Assistant

A powerful, all-in-one AI assistant built with **Streamlit** and **Google Gemini 3.5 Flash**. Features conversational chat, document summarization, and smart daily planning — all in a clean, user-friendly interface.

---

## ✨ Features

- 💬 **Chat & Q&A** — Natural, context-aware conversations with full chat history
- 📄 **Document Summarizer** — Paste text and get clear, structured summaries instantly
- 📅 **Task & Day Planner** — AI-generated time-blocked schedules based on your goals
- 🔒 **Secure API Key Input** — Your key stays in your browser; never stored on servers
- ⚡ **Fast & Efficient** — Powered by Gemini 3.5 Flash for quick responses

---

## 🛠️ Prerequisites

- Python 3.9 or higher
- A Google Gemini API key — get one free from [Google AI Studio](https://aistudio.google.com/app/apikey)
